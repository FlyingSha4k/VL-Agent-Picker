# A-P · Agent Picker

[English](README.md) · **Русский**

Небольшая программа для Windows, которая автоматически выбирает агента в VALORANT на экране выбора. Она находит иконки агентов **по картинке** (поэтому ей всё равно, на каком месте агент в списке), сама прокручивает список, если агент ниже, и кликает через AutoHotkey.

> ⚠️ **Прочитай сначала.** Правила Riot запрещают сторонюю автоматизацию игрового ввода, и Vanguard может считать это именно ею. Программа не трогает процесс игры (не читает память, не внедряется, не рисует оверлей): она только делает скриншоты и отправляет мышь, как это делал бы человек. Это снижает риск, но **не делает его нулевым**. Используй на свой страх и риск и сначала проверяй в Практике или Custom. Проект никак не связан с Riot Games и не одобрен ею.

## Возможности

- Поиск агентов по картинке: новый агент, сдвигающий список, ничего не ломает
- Список приоритета: если первый агент занят (иконка серая), берётся следующий
- Запоминает, сколько щелчков колеса вниз до каждого агента, и прокручивает список перед кликом
- Авто-режим сам определяет экран выбора агента; глобальные горячие клавиши (настраиваются)
- Режим «Обучить» сам листает список, снимает все страницы и спрашивает имена только у новых иконок
- Автономный `.exe`: всё хранит в `%APPDATA%\AgentPicker`, рантайм AutoHotkey вшит внутрь
- Тёмный интерфейс в стиле VALORANT

## Требования

- Windows 10 / 11
- VALORANT в режиме **«Окно без рамки»**; в полноэкранном эксклюзивном режиме скриншот может быть чёрным
- Для сборки или запуска из исходников: Python 3.10+

Интерфейс на русском. Геометрия откалибрована под раскладку 1920×1080 (русский клиент) и масштабируется по высоте экрана; другие разрешения должны работать, но проверены меньше.

## Быстрый старт

### Вариант А: собрать exe

1. Положи `agent_picker.py`, `build.bat`, `requirements.txt` (и по желанию свой `icon.ico`) в одну папку.
2. Запусти `build.bat`. Он поставит зависимости, скачает официальный рантайм AutoHotkey v2 и соберёт `dist\AgentPicker.exe`.
3. Запусти `AgentPicker.exe`. Он попросит права администратора: без них хоткеи и клики в игре могут не работать.

Если AutoHotkey не скачался, скачай его вручную с [autohotkey.com](https://www.autohotkey.com/), положи `AutoHotkey64.exe` в папку `_build` рядом с `build.bat` и запусти скрипт снова.

### Вариант Б: запуск из исходников

```
pip install -r requirements.txt
python agent_picker.py
```

Запускай от администратора. Если вшитого AutoHotkey нет, программа использует установленный в системе AutoHotkey v2.

## Как пользоваться

1. **Обучение.** Открой экран выбора агента (подойдёт Практика), убедись, что список в самом начале, нажми **ОБУЧИТЬ** и не трогай мышь. Окно свернётся, программа сама прокрутит список, снимет все страницы и спросит имя каждой новой иконки. Заодно запомнит, сколько щелчков колеса до каждого агента.
2. **Приоритет.** На главной вкладке выбери агента и нажми **В ПРИОРИТЕТ**. Порядок меняется стрелками ▲ ▼, верхний главный.
3. **Кнопка выбора (по желанию).** Если клик мимо кнопки подтверждения, наведи на неё курсор в игре и нажми `F7` (или кнопку **ЗАПОМНИТЬ КНОПКУ**).
4. **Запуск.** Нажми **ЗАПУСТИТЬ АВТО** или `F9`. Когда появится экран выбора, программа выберет первого доступного агента из приоритета.

### Горячие клавиши по умолчанию

| Клавиша | Действие |
|---------|----------|
| `F9` | Авто-режим вкл / выкл |
| `F11` | Выбрать прямо сейчас |
| `F7` | Запомнить позицию кнопки подтверждения (курсор на ней) |

Все клавиши меняются на вкладке **НАСТРОЙКИ**.

### Когда вышел новый агент

Открой экран выбора агента и снова нажми **ОБУЧИТЬ**. Известные иконки пропускаются, так что программа спросит имя только у нового агента и обновит прокрутки у сдвинувшихся.

## Настройки

- **Порог совпадения иконки**: насколько точно иконка должна совпасть (по умолчанию 0.80). Если агенты не находятся, снизь порог; если выбирается не тот, повысь.
- **Щелчков колеса за шаг**: шаг прокрутки при обучении (по умолчанию 3).
- **Шаблон AHK**: открывает `ahk_template.ahk`, где можно поменять тайминги кликов или число повторов. Плейсхолдеры: `{{NAME}}`, `{{AGENT_X}}`, `{{AGENT_Y}}`, `{{LOCK_X}}`, `{{LOCK_Y}}`.

## Как это работает

1. Скриншот сетки агентов сравнивается с сохранёнными шаблонами иконок (поиск по шаблону в OpenCV). Если на экране видны хотя бы две известные иконки, программа считает, что это экран выбора агента.
2. Для каждого агента из приоритета она прокручивает список (колесо через AutoHotkey) до запомненного места и ищет иконку. Серые (занятые) агенты не совпадают.
3. Найдя свободного агента, она создаёт из шаблона AutoHotkey-скрипт с точными координатами и запускает его: клик по агенту, клик по кнопке подтверждения.

## Где лежат данные

`%APPDATA%\AgentPicker\`

```
config.json             настройки, приоритет, хоткеи, позиция кнопки
ahk_template.ahk        шаблон для генерируемых скриптов кликов
agents\                 шаблоны иконок (*.png), positions.json, scrolls.json
ahk\                    сгенерированные скрипты, _scroll.ahk, runtime\AutoHotkey64.exe
crash.log               появляется только при сбое программы
```

При первом запуске программа создаёт эту папку. Если рядом с программой лежат старая папка `agents` или `picker_gui_config.json`, они переносятся автоматически.

## Если что-то не работает

| Проблема | Что попробовать |
|---|---|
| Хоткеи и клики в игре не срабатывают | Запусти от администратора; проверь, что игра в режиме «окно без рамки» |
| «Ни один агент не найден» | Снова нажми **ОБУЧИТЬ**, немного снизь порог совпадения, проверь, что список в начале при открытии экрана |
| Список прокручивается слишком мало или много | Поменяй «Щелчков колеса за шаг» и обучи заново |
| Клик попадает рядом с кнопкой подтверждения | Наведи курсор на кнопку и нажми `F7` |
| Антивирус ругается на exe | Для PyInstaller с хуками клавиатуры это обычное дело. Собери сам и добавь в исключения |
| Программа упала | Посмотри `%APPDATA%\AgentPicker\crash.log` |

## Сторонние компоненты

- [AutoHotkey v2](https://www.autohotkey.com/) (GPLv2) скачивается скриптом `build.bat` при сборке и вшивается в exe; в репозитории он не хранится.
- Используются OpenCV, NumPy, mss, PyAutoGUI, keyboard и Tkinter.
